# Plan de Aprendizaje — QA Testing con Python

Mentoría práctica. Avanzamos **módulo a módulo**. No pasamos al siguiente hasta que confirmes que entendiste el actual. Cada módulo: concepto breve + ejemplo, tú escribes el test, yo corrijo, ejecutamos (verde/rojo), mini-reto y cuestionario.

## Bloque 1 — Fundamentos
- **Módulo 1**: ¿Qué es QA? Diferencia entre QA, QC y Testing. (+ tu primer test) ← EMPEZAMOS AQUÍ
- **Módulo 2**: Tipos de pruebas (unitarias, integración, e2e, funcionales, regresión) y la Pirámide de Testing.

## Bloque 2 — Testing unitario con pytest
- **Módulo 3**: Tu primer test "de verdad" con pytest. Estructura AAA (Arrange-Act-Assert).
- **Módulo 4**: Diseño de casos de prueba: caminos felices, casos límite (edge cases) y casos de error.
- **Módulo 5**: Buenos asserts, fixtures y `@pytest.mark.parametrize`.
- **Módulo 6**: Probar excepciones y errores (`pytest.raises`).

## Bloque 3 — Calidad de los tests
- **Módulo 7**: Cobertura de código (coverage): cómo medirla y cómo leer el reporte.
- **Módulo 8**: Testing de integración (varias piezas juntas).

## Bloque 4 — El trabajo real de QA
- **Módulo 9**: Testing manual vs automatizado. Cómo documentar un buen bug report.
- **Módulo 10**: Introducción a testing E2E / UI con Playwright.
- **Módulo 11**: Buenas prácticas y qué se espera de un QA en un equipo real.
